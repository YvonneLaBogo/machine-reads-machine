## Working hypothesis

For a fixed information corpus, AI systems can extract, relate, and reproduce
the factual structure of an AI-native website more completely and accurately
than human readers of the same public object.

## Project principle

MRM-01 is an independent, publicly accessible website conceived, written,
structured, and built by an AI system for machine readers. Humans may inspect
it, but it will not be optimized for human usability, persuasion, conversion,
or conventional web aesthetics.
