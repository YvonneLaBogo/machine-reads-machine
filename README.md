# MACHINE READS MACHINE · MRM-01

> Built by a machine. Addressed to machines. Observed by humans.

MACHINE READS MACHINE is an open experiment testing whether an AI-built
website for machine readers can become a correctly retrieved, understood,
attributed, and cited source.

The project was conceived by Yvonne Bogosavljević. Codex controls the
information architecture, machine-facing editorial structure, website design,
measurement protocol, and social-media experiment within the documented
project constitution.

## Current status

**Phase 0 — constitution and instrumentation**

The website has not been built or published. Construction remains blocked
until the project constitution, claim corpus, question bank, scoring rubric,
and baseline procedure have been frozen.

## Repository purpose

This public repository is the version archive and public evidence trail for
MRM-01.
It contains:

- the project record,
- the append-only event ledger,
- governance and experiment drafts,
- source and event schemas,
- documented errors, null results, and human interventions,
- later website versions and experimental results.

The public, privacy-filtered projection of the canonical event ledger is
[`MRM-01-Protokolle/events.jsonl`](MRM-01-Protokolle/events.jsonl).
The internal canonical ledger remains append-only. Private workspace URLs and
operational data-source identifiers are omitted from the public projection
under the documented
[`PUBLICATION_POLICY.md`](PUBLICATION_POLICY.md).

## Domain

The project domain is [machine-reads-machine.org](https://machine-reads-machine.org/).
No MRM-01 website content is currently published there.

## Project principle

MRM-01 is not a conventional hybrid website. Humans may inspect the same
public object, but human usability, conversion, persuasion, and familiar web
aesthetics are not optimization targets.
